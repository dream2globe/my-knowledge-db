## 핵심 요약

Claude Code의 입문부터 심화까지 전반적인 사용법과 에이전틱 워크플로우를 구축하는 방법을 다룬 가이드입니다. 초기 설정(CLAUDE.md), 컨텍스트 관리, 커스텀 스킬 생성, Sub-Agent 병렬 실행, 그리고 Hooks 자동화 파이프라인 구축을 통해 1인 개발자가 팀급 생산성을 내는 구체적인 방법론을 제시합니다.

---

## 상세 내용

### 1. 입문: 기초 설정 및 필수 명령어

- **루트 디렉토리 실행**: Claude Code는 프로젝트 구조 탐색을 위해 항상 프로젝트 루트 디렉토리에서 실행해야 합니다.
- **CLAUDE.md 작성법**: 프로젝트의 모든 컨텍스트를 담는 파일. `/init`으로 자동 생성하며 절대 규칙, 아키텍처, 빌드/테스트, 도메인, 코딩 컨벤션 등을 명시합니다. 토큰 최적화를 위해 300자 이내로 유지하고, 폴더별로 분리하는 전략을 권장합니다.
- **트리거 키워드**: 반복적인 작업(예: 테스트 후 커밋 및 푸시)을 트리거 키워드로 묶어 하나의 명령어로 자동화할 수 있습니다.
- **핵심 단축키**: 
  - `Shift+Tab`: Plan 모드와 Accept 모드 전환. 토큰 최적화 및 컨텍스트 보존을 위해 작업을 시작할 때는 항상 Plan 모드로 시작해야 합니다.
  - `Esc`: 작업 중단. 두 번 누르면 이전 세션으로 복원됩니다.
  - 드래그 앤 드롭으로 스크린샷 입력이 가능합니다.
  - `!`: 터미널 내에서 직접 bash 명령어를 실행할 수 있습니다.
- **필수 슬래시 명령어**: 
  - 컨텍스트 관리: `/clear`, `/compact`, `/context`
  - 기타: `/models`, `/resume`, `/mcp`, `/help`, `/config`, `/export`, `/output-style`

### 2. 실전: 200% 활용 워크플로우 및 컨텍스트 관리

- **컨텍스트 관리 원칙**: 컨텍스트 윈도우는 제한적이므로 "한 세션에는 한 피처 구현" 규칙을 따르고, 필요 없는 정보 로드를 막는 "Lazy Loading"을 적용해야 합니다.
- **세컨드 브레인 & `/memory`**: 로컬 마크다운 파일(예: `memory.md`)에 의사결정 맥락과 패턴을 저장하여 활용합니다.
- **아키텍처 정리**: Mermaid 다이어그램을 활용하여 시스템 구조를 컨텍스트에 효율적으로 저장합니다.
- **무거운 작업 오프로드**: 대량의 데이터 처리나 긴 파일 파싱은 Claude 대화에서 직접 하지 말고, 처리 스크립트를 작성하게 한 후 결과 요약만 받도록 하여 컨텍스트 오염을 방지합니다.
- **WAT 프레임워크**:
  - **W (Workflows)**: 글로 명확하게 작업 흐름(순서)을 정의합니다.
  - **A (Agents)**: Self-healing 메커니즘을 적용하고, Sub-agent로 역할을 분리하여 병렬 처리합니다.
  - **T (Tools)**: 원자적 도구(작은 단위의 스크립트), MCP, Hooks 등을 적절히 조합하여 제공합니다.

### 3. 심화: 자동화 및 확장 (에이전틱 엔지니어링)

- **Skills (커스텀 스킬)**: AI에게 주는 업무 매뉴얼. 프롬프트와 달리 반복적인 복잡한 업무를 재사용 가능한 시스템으로 만듭니다. `Skill Creator` 플러그인을 사용하여 쉽게 생성 가능하며, 호출 시에만 컨텍스트를 로드하므로 매우 가볍고 효율적입니다.
- **Sub-Agent (에이전트 병렬 실행)**:
  - 메인 에이전트와 분리된 별도의 컨텍스트를 가지는 보조 에이전트를 생성합니다. (`/agent` 명령어 사용)
  - 독립적인 작업(프론트엔드, 백엔드, 테스트 생성 등)을 병렬로 처리하여 시간을 단축하고 메인 컨텍스트 오염을 막습니다.
  - `Agent Teams` 기능을 통해 리더 에이전트가 조율하고 팀원 에이전트끼리 협력하는 구조도 가능합니다.
- **Hooks (자동화 파이프라인)**: 이벤트 기반 자동화 엔진. `pre-use`, `post-use`, `notification`, `stop` 이벤트를 트리거로 삼아 린트(lint) 실행, 알림 전송 등을 자동화합니다. 타임아웃 설정이 필수입니다.
- **생산성 극대화 팁**:
  - **멀티 인스턴스 운영**: 터미널 탭 여러 개에서 각각 다른 작업을 동시에 진행 (`git worktree` 활용 권장).
  - **음성 입력 (`/voice`)**: 긴 프롬프트나 복잡한 요구사항을 빠르게 전달.
  - **다중 모델 검증**: `/export`나 커스텀 MCP를 통해 Gemini, ChatGPT 등 다른 AI 모델에게 계획(Plan)을 리뷰받아 품질을 높입니다.
